┌─────────────────────────────────────────────────────────────────────────────┐
│  FLUJO 1: CREAR ORDEN CON REPUESTOS                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. Usuario crea orden                                                     │
│     └─→ OrdenFormPage.crearOrden()                                        │
│                                                                            │
│  2. Sistema guarda orden vacía                                             │
│     └─→ OrdersService.createOrder()                                      │
│     └─→ DatabaseService.insertOrden()                                    │
│     └─→ Ionic Storage: orden_[id]                                        │
│                                                                            │
│  3. Usuario agrega repuesto                                               │
│     └─→ OrdenRepuestosComponent.agregarItem()                            │
│                                                                            │
│  4. Sistema valida stock                                                  │
│     └─→ DatabaseService.getRepuestoById(repuestoId)                     │
│     └─→ Si stock < cantidad: ❌ Error                                    │
│     └─→ Si stock ≥ cantidad: ✅ Continuar                                │
│                                                                            │
│  5. Sistema registra movimiento y descuenta stock                         │
│     └─→ InventarioService.descontarStockPorOrden()                      │
│     └─→ InventarioService.registrarMovimiento()                          │
│     └─→ DatabaseService.insertMovimiento()                               │
│     └─→ DatabaseService.updateRepuesto() (stock - cantidad)              │
│                                                                            │
│  6. Sistema agrega item a orden                                           │
│     └─→ OrdersService.addItem()                                          │
│     └─→ Cálcula subtotal: precioUnitario × cantidad                      │
│     └─→ DatabaseService.updateOrden()                                    │
│                                                                            │
│  7. Sistema recalcula totales                                             │
│     └─→ OrdersService.calculateTotals()                                  │
│     └─→ total = Σ(subtotales) + manoObra + impuestos                     │
│     └─→ DatabaseService.updateOrden(total)                               │
│                                                                            │
│  ✅ Orden lista para facturar                                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  FLUJO 2: GENERAR FACTURA Y REGISTRAR PAGO                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. Usuario solicita generar factura                                       │
│     └─→ OrdenFacturaComponent.generarFactura()                            │
│                                                                            │
│  2. Sistema valida orden                                                  │
│     └─→ Si no hay items: ❌ Error                                        │
│     └─→ Si hay items: ✅ Continuar                                        │
│                                                                            │
│  3. Sistema genera número secuencial                                      │
│     └─→ FacturaService.generarNumeroFactura()                            │
│     └─→ Formato: FAC-00001-2025                                          │
│                                                                            │
│  4. Sistema calcula totales                                               │
│     └─→ subtotal = Σ(items.subtotal)                                      │
│     └─→ impuestos = subtotal × 0.19 (IVA)                                │
│     └─→ total = subtotal + impuestos                                      │
│                                                                            │
│  5. Sistema guarda factura                                                │
│     └─→ FacturaService.generarFactura()                                  │
│     └─→ DatabaseService.insertFactura()                                  │
│     └─→ Ionic Storage: factura_[id]                                      │
│     └─→ Estado inicial: 'emitida'                                         │
│                                                                            │
│  6. Usuario registra pago                                                 │
│     └─→ OrdenFacturaComponent.cambiarEstadoPago()                        │
│     └─→ Selecciona método: efectivo/tarjeta/transferencia/cheque         │
│                                                                            │
│  7. Sistema actualiza estado                                              │
│     └─→ FacturaService.registrarPago()                                   │
│     └─→ FacturaService.cambiarEstado() → 'pagada'                        │
│     └─→ DatabaseService.updateFactura(metodoPago)                        │
│                                                                            │
│  ✅ Factura pagada y registrada                                           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
