📱 COMPILAR EN MAC - COMANDO RÁPIDO

Si quieres hacerlo todo de una vez, copia esto en Terminal de Mac:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# Si acabas de clonar desde GitHub:
git clone https://github.com/JuanRestrepo5/AUTOMOTOSYNC_DES.git && \
cd AUTOMOTOSYNC_DES && \
npm install --legacy-peer-deps && \
ionic build --prod && \
ionic capacitor copy ios && \
open ios/App/App.xcworkspace

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# O si ya tienes la carpeta (más rápido):
cd ~/AUTOMOTOSYNC_DES && \
npm install --legacy-peer-deps && \
ionic build --prod && \
ionic capacitor copy ios && \
open ios/App/App.xcworkspace

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Eso es. Después:

1. Se abre Xcode automáticamente
2. Conecta tu iPhone por USB
3. Presiona ⌘R
4. ¡Listo!
